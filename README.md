# AgentEngineeringStandards

所有工程项目共同遵守的 Agent 工作规范仓库。

## 目标

本仓库只保存跨项目通用规则，例如：
- Agent 回答方式；
- 技术分析方法；
- 代码修改原则；
- 文档组织方式；
- Git 操作规范；
- 文件修改与检查规范。

不保存任何单一项目的专属规则。

## 目录

- `AGENTS.md`：全局入口与最高层通用规则
- `docs/01_Agent回答规范.md`
- `docs/02_技术分析规范.md`
- `docs/03_代码开发规范.md`
- `docs/04_文档编写规范.md`
- `docs/05_Git操作规范.md`
- `docs/06_文件修改与检查规范.md`

## 在具体项目中使用

每个具体工程仍应保留自己的项目级 `AGENTS.md`，用于：
1. 声明遵守本仓库的通用规范；
2. 增加该项目专属规则；
3. 说明目录、架构、命名、构建、测试、硬件约束等项目特有内容。

规则优先级：
用户当前明确指令 > 当前项目规则 > 本仓库通用规则 > 其他说明性文档。

## 维护原则

修改本仓库时：
- 只增加真正跨项目通用的规则；
- 避免重复；
- 已有规则应优先修订，而不是在别处再次描述；
- 规则应可执行、可检查、可长期复用。
